# Changelog

All notable changes to the methodology and skill instructions. Dates are ISO format.

## V2.1 — 2026-10-26

Added:
- Required **Changes since last scan** section after the executive summary.
- **Borderline gates** column in the watchlist; gates within 0.10 of 0.75 must be listed with scores.
- Scoring model identifier and prompt (or hash) must be documented in the methodology.
- **Sensitivity** subsection describing how the label would change if a borderline gate moved 0.05–0.10.
- **Aggregate thematic exposure** paragraph after the hidden-concentration check.
- Evidence packets archived per stock (`references/evidence-packet-template.md`), with an archive note ending the report.
- `references/scoring-crosscheck.md`: local rubric as a fallback and cross-check when the scoring model is unavailable.
- `samples/` directory with the 2026-10-04 and 2026-10-18 V2 sample reports, README badges, and this changelog.

Changed:
- Report filename is now `diversified_bottleneck_stock_report_v2_1_YYYY-MM-DD.pdf`.
- Verification checklist extended for all of the above.

Unchanged: the seven durability tests and the conservative rule that all five conditions (gates >= 0.75) must hold for `Potentially Hard to Scale`.

## V2

- Required durability indicator (`Probably Temporary` or `Potentially Hard to Scale`) with confidence, research horizon, three-clock assessment, and flip conditions for every stock.
- Seven-test durability framework and company value-capture test.
